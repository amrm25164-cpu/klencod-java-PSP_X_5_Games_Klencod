PSP X - 5 mini games + PSP file library
افتح المشروع في Klencod IDE وابنِ APK.
الألعاب الخمسة تعمل داخل أندرويد باستخدام Canvas وJava دون مكتبات إضافية.
قسم PSP يخزن روابط ISO/CSO فقط ولا يشغلها.
محرك PPSSPP وملفات so غير مدمجة، ومجلد jniLibs فارغ.
ألعاب Homebrew يمكن الحصول عليها من مصادر مرخصة، ويجب بناء محرك PPSSPP لتشغيلها.
